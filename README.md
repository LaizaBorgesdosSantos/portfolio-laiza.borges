# Portfólio · Laiza Borges dos Santos

Portfólio com projetos de análise de dados de mídia, automação e IA.

**Site:** https://laizaborgesdossantos.github.io/portfolio-laiza.borges/

## Projetos

- **[Painel de KPIs de mídia](https://laizaborgesdossantos.github.io/portfolio-laiza.borges/painel.html):** painel interativo com dados fictícios. Investimento, impressões, cliques, conversões e receita por canal viram CPM, CTR, CPC, CPA, ROAS e ROI, com gráfico e leitura automática.
- **[Gerador de relatório de campanhas](https://laizaborgesdossantos.github.io/portfolio-laiza.borges/relatorio.html):** transforma os números do painel em um relatório semanal escrito, para cliente ou para a equipe. O texto sai de regras (se/então) e marca como hipótese o que os dados não provam.
- **[Monitor de mídia](https://laizaborgesdossantos.github.io/portfolio-laiza.borges/monitor.html)** (em construção): automação semanal que classifica as notícias sobre uma marca e envia o panorama por e-mail. O fluxo e o formato do relatório estão desenhados; a automação (n8n ou Make) ainda será montada.
- **[Currículo](https://laizaborgesdossantos.github.io/portfolio-laiza.borges/curriculo.html):** experiência, formação, habilidades e voluntariado, com opção de imprimir ou salvar em PDF.

## Como foi feito

HTML, CSS e JavaScript puros, sem frameworks. Tudo roda no navegador, sem cadastro e sem servidor; as fontes vêm do Google Fonts. Os dados dos projetos são fictícios. O site foi construído com apoio do Claude.

## Rodar no computador

Baixe o repositório e abra o arquivo `index.html` no navegador.
